## 1.0.2 三尺寸布局与深浅色

用户提供的三种尺寸手机预览截图暴露了根内容区缺少内边距、数字过度简写和大号空间利用的问题。修复通过官方 `padding`、可收缩 `frame`、`DynamicShapeStyle` 以及 `widgetBackground` 实现；`Widget.displaySize` 只用于选择密度，不作为强制根宽高。

另在本地 `dist/` 使用实际视图树生成两套桌面近似排版并用 Edge 无界面模式截图检查：三尺寸浅深色、少量调用、较小尺寸、长名称、多 Worker 与 95% 告警。参考图明确标注模拟数据及非 iOS 渲染，不进入 GitHub 或安装包，不能据此宣称 SwiftUI 排版、系统主题切换和桌面裁切已通过真机复验。

## 1.0.1 空白页面修复

桌面运行真实 `index.tsx` 启动路径，并等待其启动 Promise。修复前，空配置使两个可选 Account ID 都变成 `undefined`，比较结果为真，代码继而读取 `null.period`，复现 `TypeError: Cannot read properties of null (reading 'period')`。

修复后先判断账号和查询结果均存在，再比较账号与时段。同一首次启动回归检查通过；账号设置入口、已有账号的初始状态、账号和时段不匹配的状态一并验证。测试适配器仅模拟初次 hooks 与页面呈现，不执行 SwiftUI 排版或 iOS 页面生命周期。源码及安装包版本已升为 1.0.1；手机端仍需实际导入并确认。
